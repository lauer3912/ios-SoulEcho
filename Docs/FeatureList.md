## Technical Notes
- UIKit based (iOS 16+)
- No backend required — all generation is template-based with randomization
- Particle animation via CAEmitterLayer
- Share via UIActivityViewController
- Local storage for journal via UserDefaults
- StoreKit 2 for Premium subscription
